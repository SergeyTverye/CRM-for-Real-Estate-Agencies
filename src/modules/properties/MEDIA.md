# Галерея объекта — ТЗ v2.4.1, раздел 6

Формы создания и редактирования используют `media-upload.tsx`. Сначала сохраняется объект,
его ID остаётся в форме; затем очередь отправляет по одному файлу. Повтор отправляет только
неуспешные элементы. Совпадающие имя, тип и checksum на том же объекте позволяют безопасно
повторить запрос после потери ответа. Успешные файлы не откатываются из-за ошибки соседнего.

API (все маршруты требуют сессию; изменения также Origin и активный экземпляр):

- `GET /api/v1/properties/:id/media?archived=true` — разрешённые метаданные без storage keys.
- `POST /api/v1/properties/:id/media` — multipart `file`, `kind=photo|document`,
  необязательный `documentTypeCode` для документа. Фотография всегда имеет тип `photo`.
- `PATCH /api/v1/properties/:id/media/:documentId` — `caption`, `sortOrder`,
  `move=up|down`, `isCover`, `archived` (восстановление: `false`).
- `GET .../:documentId/file` и `GET .../:documentId/thumbnail` — потоки с одинаковой
  проверкой `documentScope`, `no-store`, `nosniff`; закрытые документы отдаются вложением.

Редактирует ответственный объекта или руководитель. Ограничение схемы и блокировка строки
Property сериализуют назначение обложки. Архивирование связи не удаляет бизнес-историю.
Восстановление глобально архивированного документа дополнительно требует автора/руководителя.
Дополнительная ссылка на публичный объект не обходит запреты общей политики документа.

JPEG/PNG/WebP перекодируются sharp без metadata, с `limitInputPixels=40_000_000`, поворотом
по ориентации и WebP-миниатюрой до 480×320. Скан сохраняет закрытый тип документа.
Используются исходные `MAX_UPLOAD_MB`, allowlist и проверка сигнатуры. SVG/HTML запрещены.
Оригинал после обработки и миниатюра находятся в существующем StorageAdapter, вне public,
в том же дереве, которое резервируется действующими средствами. Ошибки записи миниатюры
и БД очищают созданные файлы. Существующие `photo` видны независимо от старого `kind` связи;
при отсутствии миниатюры галерейный маршрут безопасно перекодирует их в памяти без записи на GET.
