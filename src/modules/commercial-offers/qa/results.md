## Ограничения данных и окружения

- Старые снимки не содержат района/назначения: выводится «Не указано». Если нет достоверной единицы цены, она явно помечается, расчёт за м² не выполняется. Не подставляем текущую карточку в старое КП. Новые автоматически заполненные условия фиксируют эти характеристики; вручную заданные условия сохраняются точно как введены.
- Логотип/контакты/реквизиты выводятся при заполнении выбранного LegalEntity. В User отсутствуют телефон/email; отдельные поля не добавлялись, рабочие контакты задаются в реквизитах. У выбранного старого демо-КП логотип и реквизиты не заполнены; их вывод отдельно покрыт integration-тестом с синтетическими данными.
- Запуск `npm run dev:webpack -- -p 3320` блокируется эксклюзивной блокировкой общей `.next/dev` другим агентом (сервер 3310). Чужой процесс не останавливался. Визуальная проверка проведена напрямую через те же application-сервисы/Chromium; HTTP API проверен вызовом route handlers в integration/authorization-тестах.
- Схема БД, миграции, зависимости и lockfile не менялись. Коммиты не создавались.
