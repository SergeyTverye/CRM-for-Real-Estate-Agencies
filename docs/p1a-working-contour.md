## Реализация и решения

| Пауза в UI | Диалог новой задачи возврата / смены статуса active или closed; причина закрытия; повторение сохраняет taskType | p1a-workflow (сервер), браузерная приёмка не выполнялась |

| Нейтральные выгрузки | DOCX с авторизованными фото/ссылками/реквизитами, HTML КП и объекта, HTML чек-листа | DOCX проверен разбором ZIP; HTML браузером не проверялся |
| Чек-лист | Шаблон по операции; статусы codebook, ответственный, дата, только доступный Document этой сделки, optimistic concurrency, аудит | p1a-workflow, p1a-access |
| Реестры | /api/v1/export/deals, /commissions, /tasks; UTF-8 BOM; списки переиспользуют фильтры/RBAC; прежний ZIP сохранён | p1a-access, p1a-workflow |
| Отчёты | Единые cohorts для цифр и /reports/detail; временная зона экземпляра; уникальные потребности; комиссии через Decimal/целые копейки | p1a-workflow |

Перспективное открытое обращение: resultCode из двух указанных кодов, statusCode != closed и связанная потребность active/paused (либо неразрешённое обращение без потребности). Обработанное обращение processed остаётся открытым для контроля продолжающейся работы. Актуальная задача: planned/in_progress со сроком >= времени формирования отчёта. Своевременность контактов: completedAt в периоде и completedAt <= dueAt, тип call_or_contact или pause_return. При пустом знаменателе показывается 100%, рядом явно указано 0 из 0.

Источник ограничивает обращения периода и связанные потребности/клиентов; через них фильтруются задачи, показы, КП, сделки и комиссии. Активные состояния и просрочки — текущий срез, остальные события имеют явно заданную дату: occurredAt, scheduledAt, sentAt, closedAt, receivedAt. Воронка переходов ограничена тем же периодом. Сумма комиссий сопровождается детализацией отдельных обязательств.

Без изменения схемы связь редакций хранится в существующем promptTemplateVersion как `revision-of:<uuid>`; это решение относится только к вручную созданным редакциям. Позиции копируются со снимком цены, адреса, площади и условий. Фотографии при выгрузке берутся из текущих доступных файлов и повторно авторизуются; бинарный исторический снимок фото схема КП не предусматривает.
