# Backlog за пределами core MVP

Идеи, которые не реализуются в v1.6.1 (ТЗ 4, 40.13), но могут понадобиться позже.

- Интеграция с IP-телефонией: автоматическая регистрация входящего звонка как LeadRequest (модель Request/Communication готова к этому, NFR-13).
- Получение лидов с площадок (Авито, ЦИАН) и автопубликация объявлений.
- Ручной merge дублей клиентов с переносом связей (ТЗ 40.2 — не входит в MVP).
- Перенос счётчиков защиты входа в PostgreSQL при горизонтальном масштабировании (ADR-0004).
- Уменьшение размера образа приложения (Next.js standalone output + отдельный слой Prisma CLI).
- HTTPS/reverse proxy профиль Compose для удалённого доступа через VPN.
- AI-контур (P3): черновики объявлений и КП, резюме истории — после стабилизации I0–I5.
- Хранить исходную цену объекта в позиции КП отдельно от переопределённой, чтобы подсказка «цена изменилась» не срабатывала на намеренно изменённых позициях.
- Явная очистка полей (null) в быстрых модальных формах и в цене позиции КП.
- API-команды «Отправить во все облака» / «Повторить ошибочные» в разделе «Эксплуатация» (сейчас — скрипты).
- Фильтры списков по локальным суткам APP_TIMEZONE (сейчас дата фильтра — UTC-сутки; отчёт считает по локальному времени) и drill-down для шагов воронки, результатов показов, причин закрытия, КП по дате отправки.
- Фильтр сделок по дате закрытия для drill-down «Завершено сделок».
- Отдельный счётчик «уже импортировано» в сводке dry-run повторной загрузки.
- Лёгкий `GET /api/v1/needs/pick` для выбора потребности в формах.
- Nonce-CSP через `proxy.ts`; уменьшение образа (Next.js standalone).
