# Руководство пользователя CRM v3.2.3

`guide.md` — редактируемый исходник, `CRM-руководство-пользователя-v3.2.3.pdf` — печатный A4 с оглавлением и закладками. Основа: копия v3.2.2; обновлены поиск, площадки, AI-разбор, ранжирование и помощник.

Сборка (Python с reportlab, Pillow; Arial):

```powershell
python scripts/docs/build-user-guide.py --version v3.2.3 --render
python scripts/docs/check-user-guide.py --version v3.2.3
```

Для `--render` нужен `pdftoppm` в PATH. Генератор создаёт временные рендеры и структурный протокол в `tmp/pdfs/guide/v3.2.3/`. Проверенные `layout-check.json` и `structure-check.json` сохранены рядом с руководством. Параметр версии не меняет исходник v3.2.2.

Новые снимки поиска: 1366×768, deviceScaleFactor=2, без контактов продавцов. Помощник: ранее записанный DEMO на синтетических данных, без новых LIVE-вызовов. Остальные иллюстрации сохранены из предыдущего руководства и не подтверждают новый LIVE-прогон.

Фактические ограничения, расходы и результаты: `docs/vkr/live-search-v323-e2e.md` и JSON рядом. Выдача источника не гарантирует полноту рынка, проверку собственника или юридический статус апартаментов. Число комнат пока проверяют по карточке.
