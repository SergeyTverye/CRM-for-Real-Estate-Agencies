# ADR-0004. Ограничение попыток входа в памяти процесса

- **Статус:** принято
- **Решение:** счётчики неудачных попыток по ключам `login` и `login+IP` хранятся в памяти application-контейнера: после `LOGIN_MAX_FAILURES` неудач за окно — блокировка на `LOGIN_LOCK_MINUTES`, плюс нарастающая задержка ответа. Сообщение одинаково для существующего и несуществующего логина; для несуществующего логина выполняется проверка против фиктивного Argon2-хэша (выравнивание времени).
- **Почему:** в MVP один экземпляр приложения, Redis запрещён без необходимости (ТЗ 10). Сброс счётчиков при перезапуске контейнера допустим.
- **Пересмотр:** при горизонтальном масштабировании — перенести счётчики в PostgreSQL.
