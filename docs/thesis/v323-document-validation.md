## Визуальная проверка

Все 109 страниц альбома и все 19 страниц отчёта отрендерены `pdftoppm -r 85 -png`. Просмотрены 19 обзорных листов альбома и четыре отчёта, охватывающие каждую страницу. Дополнительно увеличены страницы отчёта с архитектурой, сводной таблицей сценариев и итоговой регрессией. После исправлений повторно просмотрены затронутые листы альбома и последние страницы отчёта. Обрезаний, наложений, отсутствующих кириллических символов и пустых страниц не обнаружено. Длинные таблицы продолжаются с повторной шапкой, пункты перечня развития не разрываются между страницами.

JPEG в альбоме: качество 85, ширина не более 2000 px, пропорции сохранены, обрезка не применяется. Каждый кадр занимает отдельную страницу. Для мелких деталей интерфейса предусмотрено увеличение PDF. Лимит альбома 60 МБ соблюдён.

Подписи дополнены обозначением QA/LIVE/сохранённых результатов/DEMO и исторической ревизии. Исходные PNG и captions.json не изменялись. Исправления в генераторе:

- server/01-login-form.png показывает «Сегодня» после входа, формы входа в кадре нет.
- server/04-requests-list.png показывает карточку клиента после обращения, не список обращений.
- server/07-need-matching.png показывает пустую вкладку предложенных объектов.

Эти ограничения изображений отражены в разделе 12 отчёта. Успешность сценариев QA устанавливается первичными протоколами, а не названием PNG.

Проверяются отсутствие пустых страниц и missing glyphs, границы каждого символа, встроенные шрифты, одно изображение на иллюстративную страницу, последовательные номера 1–107, ссылки оглавлений, наличие текста итоговой регрессии. Проверка синтаксиса генератора через Python compile — PASS.

SHA-256 PDF, исходника отчёта, размеры и итоги проверок: `v323-pdf-build.json`. Номер/страница/исходный путь/режим/подпись и SHA-256 каждого PNG: `v323-album-manifest.json`. Промежуточные PNG не входят в коммит, они воспроизводятся генератором.

## Воспроизведение

```text
python scripts/docs/build-thesis-album.py --render
python scripts/docs/build-thesis-album.py --check-only
```

Нужны Python с reportlab, Pillow, pypdf, pdfplumber, Poppler в PATH и Arial из Windows Fonts. Для этой сборки использован bundled Python Codex: reportlab 4.4.9, Pillow 13.0.0, pypdf 6.21.4. `mmdc` в node_modules отсутствует, архитектура нарисована векторными средствами ReportLab по схеме Mermaid исходника.

При изменении финальной регрессии пересобрать только отчёт: `python scripts/docs/build-thesis-album.py --report-only --render`, затем заново просмотреть его страницы. Хэши и размеры в этом протоколе при необходимости актуализировать по JSON.

Финальный прогон приложения и статус релиза фиксируются координатором в `docs/acceptance/v323/README.md`. Этот протокол их не заменяет.
