# Поиск объектов: краткая инструкция

## Где включать источники

1. Руководитель открывает **«Источники поиска»** (`/settings/sources`).
2. Включает глобальный скрапер, браузерный режим (Chromium) и нужные площадки: Циан, Мир Квартир, OnRealt, Домклик, Яндекс Недвижимость, Юла, Авито.
3. Сохраняет настройки. Скрапер работает независимо от Яндекс AI и не расходует бюджет ИИ.

## Подключение Яндекс AI (ключ и каталог)

1. Руководитель открывает **«Настройки Яндекс AI»** (`/settings/ai`).
2. В разделе «Подключение Яндекс AI» вводит ключ API и Folder ID. Ключ вводится в поле пароля; сохранённые значения не показываются повторно.
3. Нажимает «Подключить Яндекс AI» (или «Заменить подключение Яндекс AI»). Данные сохраняются в защищённом хранилище текущего профиля Windows; на сервере подключение задаётся администратором окружения.
4. В серверном режиме ввод через UI недоступен — ключи задаются администратором окружения.

Безопасность: ключ и каталог никогда не возвращаются в браузер, не попадают в логи, аудит и ошибки. Повторный показ сохранённого ключа невозможен; для замены введите новый.

## Доступность источников и Яндекс AI

- На странице поиска видны статусы: скрапер, браузерный режим, активные площадки, состояние Яндекс AI.
- Если ключ не задан, показывается «Требуется подключение Яндекс AI», а не «ИИ отключён».
- Отсутствие тарифа каталога показывается отдельно как недоступность тарифа, а не как отключение ИИ.
- `blocked`/`timeout`/`error` у источника не означают снятие объекта; при частичном отказе успешная выдача сохраняется.
- CAPTCHA и блокировки площадок возможны; автоматического обхода всех сайтов нет.
- Поиск по площадкам работает без ИИ; ИИ нужен для разбора запроса, анализа описаний и веб-резерва.

## Фильтры

- Основные фильтры (город, операция, цена, площадь, назначение, площадки) видны сразу и могут сворачиваться целиком; кнопка запуска поиска находится над ними.
- Дополнительные (этаж, районы, коммуникации, свежесть) — в отдельном сворачиваемом блоке «Расширенные фильтры»; выбранные сохраняются даже в свёрнутом виде.
- Счётчик показывает число активных расширенных условий; отдельная кнопка сбрасывает только их.
- Подсказки доступны с клавиатуры.
- Клиент и потребность можно не указывать; их блок может сворачиваться.
- «Жилая» (`residential`) и коммерческие назначения объединяются по ИЛИ; если ни одно не выбрано, проверяются коммерческие по умолчанию.
- Неизвестный обязательный признак (например, этаж) не считается подтверждением и попадает во вкладку «Требуют проверки».

## Устранение неполадок AI и тарифов

- Если показано «Требуется подключение Яндекс AI», проверьте ключ API и Folder ID в `/settings/ai` или настройки администратора окружения в серверном режиме.
- Если показана недоступность тарифа, проверьте каталог тарифов в `/settings/ai`; публичный каталог инициализируется при запуске, а пользовательские тарифы, история и настройки не перезаписываются.
- Ключ и каталог не показываются повторно; для замены введите новые значения.
- В серверном режиме ввод ключа через UI недоступен.
- Настоящий запрос к провайдеру отправляется только при подтверждённых ключе и тарифе; готовые вызовы учитываются по тарифу каталога.
- Проверки с fake/test-ответами не подтверждают LIVE.

## Примечания

- Полный сбор по всем сайтам и всем фильтрам не заявляется.
- CAPTCHA и блокировки площадок возможны; автоматического обхода нет.
- Поиск по площадкам работает без ИИ; ИИ нужен для разбора запроса, анализа описаний и веб-резерва.
## Локации и типы объектов v3.2.3

В «Найти локацию» доступны город, населённые пункты области и пресеты. Несколько выбранных локаций — ИЛИ. Для Бердска снимите Новосибирск, иначе поиск охватит оба города. «Новосибирск и пригороды» включает Бердск, Обь, Кольцово и Краснообск. «Область целиком» шире этого пресета. «Академгородок» ищет по Советскому району: проверяйте точный адрес.

Выберите «Квартира (жилая)», «Дом / коттедж», «Апартаменты (нежилое)» или «Любое нежилое». Для офиса/склада используйте назначения. Юридический статус апартаментов подтверждают документы. Число комнат проверяется по карточке; выбор квартиры не ограничивает выдачу двушками.

## Браузерные проверки и ручной путь

Циан и Яндекс поддерживают автоматическую навигацию обычного Chromium при включённом браузерном режиме и разрешении руководителя. CAPTCHA требует разрешённого ручного действия пользователя; защита не обходится. При тайм-ауте или блокировке не считайте источник успешно проверенным.

Авито/Домклик: откройте предложенный поиск площадки, найдите карточку и используйте «Импорт по URL» либо ручное заполнение, если площадка не отдаёт данные. Открытие внешнего поиска само не добавляет объявление. Юла поддерживает квартиры, дома, комнаты и обе операции; неподдерживаемые фильтры отражаются в статусе.

## AI-разбор и ранжирование

В «Расширенные фильтры» введите запрос, нажмите «Разобрать и показать изменения». Сравните локации, тип, бюджет, площадь и период цены, затем «Подтвердить условия». Поддерживаются несколько локаций и пресеты; разбор сам не запускает поиск. Для аренды без указанного периода уточните цену, для двушки проверьте комнаты вручную.

Примеры: «Склад от 300 метров у Оби в аренду», «Апартаменты в Новосибирске на продажу», «Любое нежилое до 50 тысяч в месяц в Новосибирске и пригородах». Для полного сброса прежних ограничений начинайте с «Новый поиск».

Выберите 2–10 объявлений и нажмите «Ранжировать выбранные с ИИ». Рекомендация содержит причины по критериям; она не подтверждает доступность и собственника. Платные операции расходуют бюджет даже при отказе применить черновик. Ручной поиск продолжает работать без AI.

## Помощник в клиенте и задаче

Создайте новый диалог на нужной карточке. Помощник использует доступную по вашей роли сводку, сроки и открытые задачи; список ограничен. При смене карточки создайте новый диалог. Черновик следующего действия проверьте и подтвердите в форме; автоматической отправки сообщений нет.

Полное руководство: [v3.2.3](user-guide/v3.2.3/guide.md).
