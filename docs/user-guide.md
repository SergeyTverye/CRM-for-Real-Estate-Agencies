# Краткая инструкция пользователя

## Главный принцип

**У каждой потребности клиента в работе должно быть следующее действие** — задача с датой. Система не даст
оставить потребность «в работе» без следующего шага, «на паузе» без даты возврата и закрыть её без причины.

## Риелтор

1. **Входящий звонок** — «+ Создать → Обращение». Укажите канал и источник, найдите клиента или введите имя и телефон,
   выберите объект, по которому звонят, запишите итог и следующее действие. Если звонят по объекту другого риелтора,
   клиент закрепится за ним («чей объект, того и клиент») — система покажет, кому передано.
   Если контакт уже есть у другого сотрудника, система не покажет чужую карточку: нажмите «Передать руководителю».
2. **Сегодня** — стартовый экран: просрочки сверху, затем звонки, встречи и показы, предложения, договоры, реклама,
   прочее; ниже — ближайшие 7 дней. Кнопки «Выполнить» (с итогом и следующим шагом) и «Перенести».
3. **Потребность** — параметры запроса, блок «Следующее действие», «Подбор» (подходящие объекты с объяснением
   совпадения и отметкой ранее предложенных), предложенные объекты, показы, история этапов, коммуникации.
4. **Показ** — после показа «Зафиксировать результат»: результат, комментарий и сразу что дальше —
   следующее действие, пауза с датой возврата, закрытие с причиной или успех.
5. **Коммерческое предложение** — из «Подбора» выберите объекты → «Создать КП»; укажите ИП/ООО, сформируйте DOCX.
   Цены в КП фиксируются на момент подготовки и не меняются при изменении объекта.
6. **Сделка** — объект, участники, ИП/ООО, комиссии отдельными строками; при закрытии система предложит
   постсделочные задачи (по умолчанию руководителю).

Вы видите своих клиентов и весь каталог объектов. Контакты собственника чужого объекта скрыты —
«Запросить доступ» отправит запрос руководителю.

## Руководитель

Всё, что доступно риелтору, плюс: «Сегодня» в режиме «Все» с фильтром по сотруднику, **Отчёты** (каждая цифра
открывает исходный список), **Импорт**, **Эксплуатация** (копии и их проверка), **Администрирование**
(пользователи, доступ к контактам собственников, юрлица, справочники, журнал аудита), исторический архив сделок.

## Если что-то пошло не так

- «Запись была изменена другим пользователем» — нажмите «Обновить данные» и повторите изменение.
- «Внутренняя ошибка… код запроса» — сообщите код руководителю: по нему находится запись в журнале.
- Забыли пароль — руководитель выдаст временный.

## Новые рабочие разделы v2.4.1

### Перспективное обращение и возврат из паузы

Если работа продолжается, выбирайте перспективный результат и сразу назначайте следующую задачу, исполнителя и срок. Отсутствие подходящего объекта не закрывает потребность. Для отказа/спама/разовой услуги укажите причину. Очередь нарушений и просрочки доступны на «Сегодня», руководителю — также в контрольных показателях.

Для paused нужна именно задача «Возврат из паузы» (pause_return). При завершении/отмене последней такой задачи создайте новую с датой или одновременно измените статус потребности. Обычная задача это правило не заменяет.

### Поиск объектов и подборка

1. Откройте «Поиск объектов» либо перейдите из потребности: её связь будет предвыбрана. Проверьте город; по умолчанию Новосибирск.
2. Введите русский запрос, нажмите «Разобрать с ИИ», если разрешено. Проверьте распознанные условия и вопрос уточнения, исправьте фильтры до «Искать». Без ИИ заполните их вручную. Для аренды обязательно выбрать единицу цены.
3. Назначения и районы объединяются по ИЛИ, разные группы — по И. «Строго первый» исключает -1/6; неизвестный этаж требует проверки. «Частное лицо» не подтверждает собственника.
4. Просмотрите карточки/таблицу, вкладки совпадений, требующих проверки и исключённых; читайте цитаты, источник и дату. Обязательное неизвестное условие не является подтверждением. Предпочтения меняют ранжирование.
5. Посмотрите статусы источников. blocked/timeout/error не означают снятие объекта. При partial успешная выдача сохраняется. Web-поиск запускайте вручную при разрешении; авто возможен только при полном техническом отказе и доступном бюджете. Исправная пустая выдача не вызывает авто.
6. «В закладки» сохраняет личную заметку; «В подборку клиента» создаёт кандидата конкретной потребности. Эти действия не добавляют объект в общий каталог и не означают отправку клиенту.
7. «Уточнить» создаёт задачу. В проверке сотрудника отдельно запишите актуальность, подтверждение цены/собственника, дату следующей проверки. Данные площадки остаются отдельными.
8. «В каталог CRM» — явный перенос. При неполной идентичности проверьте первоисточник вручную; повторный перенос возвращает тот же объект. «Предложить клиенту» создаёт отдельный факт предложения, «В КП» добавляет Property в черновик. Для web-кандидата нужны проверяемый источник и проверка сотрудника.
9. «Мои поиски» сохраняет название, город, фильтры и источники; запускается вручную. Новизна/цена сравниваются с предыдущим успешным результатом. CSV результатов предназначен для Excel и содержит источники.

Фотографии внешних площадок автоматически не используются. В записанном demo-режиме видна плашка; такой поиск не подтверждает доступность сайта. Сохранённые закладки/подборки остаются при отказах источника.

### Галерея объекта

В создании/редактировании выберите несколько фото и документов. Сначала сохраняется объект, затем очередь файлов; не создавайте объект повторно при сбое. Для каждого файла виден итог, повторяйте только неудачные. До отправки лишние файлы можно убрать из очереди.

В карточке — вкладки «Фотографии» и «Документы»: миниатюры, увеличение, клавиатурная навигация, подписи, порядок и главное фото. Архивирование не удаляет историю; восстановление доступно в архивном списке при наличии прав. Менять медиа может ответственный объекта или руководитель. Закрытый скан не становится публичным фото; скачивание всегда проверяет права.

### Редакции КП, печать и чек-лист сделки

Выберите несколько объектов, настройте порядок/исключите лишние, укажите текст, примечания и юрлицо. Предпросмотр и DOCX используют снимки цены/адреса/площади/условий; изменение карточки объекта их не меняет. Фото при выгрузке берутся из текущих доступных файлов. «Новая редакция» копирует исходные снимки в draft; «Отправлено» отмечайте отдельным действием после фактической отправки.

Печатные страницы: `/offers/{id}/print`, `/properties/{id}/print`, `/deals/{id}/checklist/print`. Откройте страницу и печать браузера. Сохранение в PDF браузером не означает наличие серверного PDF-конвертера. Нейтральный DOCX не является утверждённым фирменным договором.

В сделке инициализируйте чек-лист, если его ещё нет. По каждому пункту выберите «Нет / На проверке / Проверено / Не требуется», исполнителя, дату и доступный документ этой сделки. Достаточность документов определяет сотрудник. При закрытии выберите подходящие постсделочные задачи, сроки и исполнителей.

### Календарь и уведомления

`/calendar`: день, неделя, месяц, повестка; фильтры сотрудника/типа/статуса. Задача отображается по сроку, показ — по назначенному времени, встреча — интервалом. Встречу можно создать/изменить/архивировать. Перенос задачи/показа использует исходную запись; повторяющуюся встречу редактируйте как серию. Пересечения показываются предупреждением.

Часовой пояс установки — Asia/Novosibirsk, UTC-значения БД сохраняются. Личная встреча другим сотрудникам, включая руководителя, показывается как «Занято». Свободные интервалы учитывают только известные начало/конец; срок задачи не является длительностью занятости.

Колокольчик и `/notifications` показывают ваши уведомления: открыть источник, прочитать одно/все или «Напомнить позже». Отложенное уведомление не переносит задачу. Интервал напоминания: в момент события, 15 минут, час, день или свой. Доставка работает фоновым worker без открытого браузера; после переноса события будущие уведомления пересчитываются. Email/push/SMS/MAX не входят в P1.

### Настройки ИИ и отчёты руководителя

Руководитель открывает `/settings/ai`: режимы ИИ/скрапера/браузера, семь площадок, ручной web и отдельный автоматический резерв, модели, контекст, лимиты и месячный бюджет, версии тарифов. Секретный API-ключ вводится в серверную конфигурацию, не в форму. ENV может запретить режим или уменьшить лимит. При отсутствующем тарифе вызов запрещается. Сотрудник видит собственный остаток, руководитель — журнал расходов. Оценка и известный факт различаются; неизвестный расход не считается нулём.

В отчётах нажмите KPI для перехода к исходным записям: период, источник и сотрудник сохраняются. Текущие просрочки — срез, выполненные контакты считаются по completedAt; КП — по sentAt, закрытые сделки — по closedAt.

При ошибке проверки исправьте отмеченные поля; при конфликте версии обновите данные перед повторным сохранением. При запрете доступа обратитесь к руководителю. Для длинного поиска дождитесь результата и статусов источников, не повторяйте платные команды из-за ожидания. Браузерная приёмка новых экранов и скриншоты **в процессе**; подробные фактические статусы — [приёмка](acceptance/v241).
