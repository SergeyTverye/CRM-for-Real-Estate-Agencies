# Установить CRM на Windows

Статус: установщик a982 прошёл CI, но установленная программа пока не принята: карточка клиента возвращает 500. Проверенного EXE для конечных пользователей пока нет; следующее исправление в работе. Не запускайте случайные копии.

1. Получите `CRM-Setup-Windows-x64.exe` и SHA-256 из одного выпуска GitHub Actions. Текущий артефакт: 585 556 902 байт, SHA-256 `1c818d455cf758edcba5b12aa591f1956c28f4cd8f919772304f6b062b57a0ed`. Не используйте размеры и хэши старых сборок.
2. Запустите установщик, выберите каталог программы, нажмите «Установить». Установка предназначена текущему пользователю. В меню «Пуск» появится RealEstateCRM; ярлык рабочего стола выбирается на последней странице.
3. Запустите CRM. Дождитесь проверки локального сервера. Интернет, Docker, PostgreSQL и установленный Node.js для первого запуска не нужны: Node и Chromium включены в программу, WebView2 — в offline installer.
4. В мастере задайте имя, логин и свой пароль руководителя (от 10 символов, буквы и цифры). Выберите пустую базу или демонстрационные записи. Затем войдите созданной учётной записью.

Рекомендуемый каталог: `%LOCALAPPDATA%\RealEstateCRM\data`; документы — `files`, резервные копии — `backups`, журналы — `logs` рядом. Программа хранится отдельно. Мастер подтверждает стандартный локальный каталог; произвольный выбор места SQLite в этой версии не включён. Не помещайте рабочую базу в облако или сетевую папку. Переносите состояние через проверенные архивы.

При закрытии окна выберите сворачивание в трей или завершение. В трее напоминания и очередь отправки уже созданных переносимых архивов продолжают работать. После полного выхода фоновые задания остановлены до следующего запуска. Повторный запуск ярлыка открывает существующее окно.

«Создать резервную копию» в трее временно останавливает сервер и worker, создаёт и проверяет зашифрованную локальную защитную копию, затем запускает их снова. Ключ такой копии защищён DPAPI текущего профиля Windows. Это страховка локальной установки; для USB или другого ПК нужен переносимый backup с отдельно сохранённым recovery key. Защитные снимки не отправляются в облака автоматически. При заполнении лимита архива создание завершается ошибкой, а предыдущие копии сохраняются.

Для обновления запустите новый установщик поверх старого. При изменении версии CRM сначала создаёт зашифрованный снимок, применяет SQLite-миграции и проверяет readiness. При ошибке восстанавливает SQLite и прежнюю отметку версии; файлы миграциями не изменяются. Защитный архив сохраняется. Откат бинарного установщика не автоматизирован: сохраните предыдущий EXE.

Удаление: «Параметры Windows → Приложения → Установленные приложения → RealEstateCRM → Удалить». По умолчанию база, документы, локальные копии и настройки остаются. Повторная установка открывает их. Для полного удаления выберите флажок удаления данных и подтвердите отдельное предупреждение. Сначала проверьте копию на внешнем носителе. Общий WebView2, другие приложения и облачные архивы не удаляются.

Если запуск не удался, окно диагностики показывает безопасный код и путь к `%LOCALAPPDATA%\RealEstateCRM\logs\supervisor.log`. Не отправляйте полные рабочие журналы публично. Установка не требует отключать Defender, UAC или брандмауэр.

Подпись не подтверждена. Windows может показать SmartScreen «Неизвестный издатель». Проверяйте источник выпуска и SHA-256; устанавливайте только одобренный организацией файл.

| Требование | Значение |
|---|---|
| ОС | Windows 10 x64 22H2 (19045+) или Windows 11 x64 |
| Размер установщика a982 | 585 556 902 байт |
| Диск для программы и данных | По фактическому объёму; полные копии требуют свободного места |
| Потребление памяти | Не измерено на потребительских Windows для этой сборки |

Потребительские Windows 10/11 VM-проверки остаются заблокированы решением пользователя. Автоматизированный lifecycle проверяется на Windows Server 2022/2025 и не подтверждает DT-01/02.
