# AT-16 — контекстный AI-чат

Дата: 05.11.2026. Требования: ТЗ v3.1 §7, AT-16.

**Предусловия:** миграции v3.1 и ai_chat_call_types; три синтетических сотрудника и раздельные клиенты; AI включён только в тестовом процессе; подставлен FakeResponsesProvider. Для UI — демо на 3411 с перехватом всех chat-запросов.

**Действия:** открыть чат из карточки; найти клиентов и задачи; запросить таймлайн чужого клиента; подготовить Task и КП; проверить отсутствие бизнес-записей до решения; подтвердить одновременно дважды; отклонить другой черновик; исчерпать бюджет; открыть чужую сессию прямым URL; передать клиента другому риелтору и повторно открыть историю.

**Ожидание:** доступны только разрешённые записи; имена/контакты не передаются как исходные DTO; нейтральная ошибка/404; предпросмотр со ссылками; подтверждение создаёт одну запись через штатный сервис, отклонение — ни одной; при бюджете 0 провайдер не вызывается; потерянный доступ закрывает старые ссылки.

**Факт:** новый тестовый контур и целевая регрессия 153/153 PASS; браузерный smoke 1/1 PASS; tsc и целевой ESLint PASS. Реальная PostgreSQL `crm_test_g`; e2e UI fake и LIVE synthetic demo разделены.

**Доказательства:** [протокол, ограничения, журнал 6 LIVE-вызовов и 2 скриншота](../../ai-chat.md), `tests/unit/ai-chat.test.ts`, `tests/integration/ai-chat.test.ts`, `tests/authorization/ai-chat.test.ts`, `tests/e2e/ai-chat.ui.spec.ts`.

**Статус:** PASS для автоматического fake/CRM-контура. LIVE PARTIAL: исправление санитизации ISO-даты подтверждено unit-тестом, но не повторным платным вызовом; исходная квота 6 исчерпана. Нет заявления о финальном production release gate всей ветки.
