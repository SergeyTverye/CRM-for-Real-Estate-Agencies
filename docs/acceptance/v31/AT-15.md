# AT-15 — Шаблоны

Дата: 05.11.2026. Требования: ТЗ v3.1 §10, AT-15.

**Критерий PASS:** четыре режима DOCX/XLSX, загрузка/версия/архив без изменения кода, визуально корректные файлы.

**Предусловия:** миграции v3.1; отдельная БД `crm_test_f`; crm_demo для браузера; LibreOffice/PyMuPDF для визуальной проверки.

**Данные:** синтетика; примеры `templates/examples/`.

**Шаги:** проверить Markdown→DOCX, DOCX fill, XLSX fill, XLSX registry, версии/архив, snapshot, нормализованные Document links, RBAC, formula injection protection, визуальную корректность.

**Ожидаемый результат:** unit 29/29, integration+authorization 8/8, browser 3/3 PASS; файлы физически вне PostgreSQL; запрещённые поля не попадают в snapshot.

**Фактические доказательства:** `docs/templates.md`, `tests/unit/document-templates.test.ts`, `tests/integration/document-templates.test.ts`, `tests/authorization/document-templates.test.ts`, `tests/e2e/document-templates-demo.mjs`, доказательства `D:/crm-review/templates/`.

**Статус:** PARTIAL до общей приёмки финального SHA. Прежнее ограничение `DocumentCollection` снято текущей миграцией и подтверждено DEMO ниже; production release gate этот прогон не заменяет.
## DEMO v3.1 — 06.11.2026

**Режим / предусловия:** синтетическая `crm_demo`, существующие миграции v3.1, порт 3416, 1440×900 (мобильные 390×900), Asia/Novosibirsk. AI/web/scraper отключены в сервере съёмки.

**Действия и фактический результат:** Четыре режима templates/examples: markdown_docx/docx/xlsx/xlsx_registry, по две неизменяемые версии и четыре сохранённых файла. Из StorageAdapter экспортированы реальные байты с совпадением checksum. Все четыре файла отрендерены LibreOffice → PDF → PNG, по одной странице, просмотрены полностью; DOCX дополнительно через штатный render_docx.py. Публикуются DOCX-подборка и XLSX-подборка на 1440×900 с сохранением пропорций. Две связи DocumentCollection подтверждены в БД. Предпросмотр формирования показан без дополнительного сохранения.
