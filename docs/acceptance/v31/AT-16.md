# AT-16 — AI-чат

Дата: 05.11.2026. Требования: ТЗ v3.1 §7, AT-16.

**Критерий PASS:** данные только разрешённого клиента, ссылка на запись, черновик → подтверждение, отказ от изменения и бюджетные ограничения.

**Предусловия:** миграции v3.1 и `ai_chat_call_types`; три синтетических сотрудника и раздельные клиенты; AI только в тестовом процессе; `FakeResponsesProvider` для fake-контура.

**Данные:** DEMO (crm_demo, порт 3411) + синтетика; 6 реальных вызовов Yandex AI.

**Шаги:** открыть чат из карточки; найти клиентов/задачи; запросить таймлайн чужого клиента; подготовить Task и КП; проверить отсутствие бизнес-записей до решения; подтвердить дважды; отклонить черновик; исчерпать бюджет; открыть чужую сессию прямым URL; передать клиента и повторно открыть историю.

**Ожидаемый результат:** только разрешённые записи; нейтральная ошибка/404; предпросмотр со ссылками; подтверждение создаёт одну запись, отклонение — ни одной; при бюджете 0 провайдер не вызывается; потерянный доступ закрывает старые ссылки.

**Фактические доказательства:** `docs/ai-chat.md`, `tests/unit/ai-chat.test.ts`, `tests/integration/ai-chat.test.ts`, `tests/authorization/ai-chat.test.ts`, `tests/e2e/ai-chat.ui.spec.ts`, скриншоты `docs/screenshots/vkr/live-ai/v31-chat-*.png`, `docs/screenshots/vkr/live-ai/v31-chat-usage.json`, `v31-chat-evidence.json`.

**Статус:** PASS для автоматического fake/CRM-контура. LIVE PARTIAL: исправление санитизации ISO-даты подтверждено unit-тестом, но не повторным платным вызовом; исходная квота 6 исчерпана. Не заявляется финальный production release gate всей ветки.
