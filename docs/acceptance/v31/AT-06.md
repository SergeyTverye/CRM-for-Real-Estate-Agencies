# AT-06 — Отказ и восстановление

Дата: 06.11.2026. Требования: ТЗ v3.1 SR-05/06, AT-06. **Статус: PASS (DEMO, серверный контур и Docker HITL)**.

## Предусловия и данные

Существующие миграции v3.1, durable SearchRun queue, отдельные `crm_test_d` / `crm_test_hitl_docker`. Синтетические карточки и контролируемые 429/CAPTCHA/тайм-ауты, без платного AI. Реальная PostgreSQL и Chromium; произвольные внешние URL стендом не обслуживаются.

## Действия → ожидаемый и фактический результат

| Проверка | Результат |
|---|---|
| CAPTCHA → ввод сотрудника → тот же run → результат | PASS; snapshot/source/result сохранены в исходном SearchRun, повторный complete идемпотентен |
| Повторная CAPTCHA на второй странице | PASS; первая карточка сохранена, run partial, source blocked, session failed/blocked_again, ручной путь |
| Общий срок сессии | PASS; expired, source blocked, Chromium закрыт, собственный профиль удалён, frame=null |
| Отмена задания через API | PASS; cancelRequested, session cancelled/search_cancelled, source cancelled; fence предотвращает поздний commit |
| Graceful остановка владельца браузера | PASS; failed/process_stopped, source blocked, профиль удалён; это режим `restart` Docker runner, без имитации настоящего SIGKILL |
| Потерянный runtime / process_lost | PASS в unit; GET/frame не обещают восстановить cookies, возвращают безопасное закрытие |
| Durable restart/recovery, stale heartbeat и отмена адаптера | PASS в integration очереди; завершённые источники не запрашиваются заново, частичные snapshots сохранены |
| 429 и повторный отказ | PASS в integration/unit; прежние snapshots остаются; Retry-After и безопасные лимиты адаптера проверяются unit |
| Срок при зависшем continuation/БД, поздний launch и cleanup failure | PASS в lifecycle unit; браузер закрывается до БД, ошибка cleanup не объявляется успехом |
| Конкурентные claims / лимит Chromium | PASS в PostgreSQL; advisory lock сериализует владельца/источник и общий budget; late active-write не воскрешает терминальный сеанс |
| Чужая сессия / HTTP redirect | PASS; чужой manager получает 404 на всех пяти API; redirect на внешний домен закрывается до незащищённого перехода |
