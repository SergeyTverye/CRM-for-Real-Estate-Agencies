## Журнал найденных и исправленных дефектов

1. SQLite-миграции документов и периода цены падали бы на заполненной базе вне транзакции — добавлены PRAGMA, тесты обоих путей.
2. Циан ошибочно классифицировался как parse_failed — теперь needs_user_action с понятной причиной.
3. Жилая выдача Мир Квартир/OnRealt обрывалась по TIMEOUT — параллельные ветви с лимитом частоты.
4. Страницы-каталоги оценивались как кандидаты — теперь отклоняются; дубли при разной записи адреса помечаются.
5. Ложные дубли разных домов — исправлено.
6. AI-01: терялась верхняя цена при разборе запроса.
7. AI-02: неизвестный период цены превращался в «за объект» и сравнивался.
8. AI-RANK-LIVE-01: ответ модели нарушал схему (5 оснований вместо 1–3).
9. Кэш AI-ранжирования не учитывал пользователя.
10. Форма договора не предупреждала о несохранённой смене ответственного и напоминания.
11. CI: Chromium устанавливался после unit-тестов; таймаут SQLite-теста обновления на медленных раннерах.
