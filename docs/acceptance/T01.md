# T01. Вход трёх пользователей и проверка различий ролей

- **Дата проверки:** 2026-11-03
- **Версия:** см. commit в `IMPLEMENTATION_REPORT.md`
- **Среда:** PostgreSQL 18.6 (compose.test.yaml), Node.js, Vitest 5 / Playwright 1.64

## Предусловия
Тестовая БД с учётными записями manager, realtor1, realtor2 (seed / фикстуры).

## Тестовые данные
Синтетические учётные записи; пароли — тестовые значения фикстур.

## Действия
1. Вход каждым пользователем.
2. Риелтор открывает /admin/users, /reports прямым URL и вызывает административные API.
3. Руководитель создаёт пользователя, меняет роль, деактивирует и восстанавливает учётную запись, сбрасывает пароль.
4. Вход деактивированным пользователем; вход с неверным паролем.

## Ожидаемый результат
Все трое входят; роли различаются на сервере; риелтор получает /forbidden и 403; изменения ролей и статусов в AuditLog; деактивированный не может создать сессию; неверный пароль — общее сообщение.

## Фактический результат
Совпадает с ожидаемым.
