# T10. CommercialOffer со snapshot и Document с legal_entity_id

- **Дата проверки:** 2026-11-03
- **Версия:** см. commit в `IMPLEMENTATION_REPORT.md`
- **Среда:** PostgreSQL 18.6 (compose.test.yaml), Node.js, Vitest 5 / Playwright 1.64

## Предусловия
Потребность риелтора 1, два объекта.

## Тестовые данные
Синтетические объекты 100 000 ₽ и 120 000 ₽.

## Действия
1. Создание КП из двух объектов в заданном порядке.
2. Перевод в prepared без ИП/ООО (отказ), выбор ООО, prepared → sent с follow-up задачей.
3. Формирование DOCX.
4. Изменение текущей цены объекта.

## Ожидаемый результат
Позиции в порядке выбора, snapshot цены/адреса/площади/условий; Document типа commercial_offer наследует legal_entity_id и связан с КП; после изменения цены КП показывает исходную цену, расхождение подсвечено.

## Фактический результат
Совпадает с ожидаемым.
