# T03. Жизненный цикл ClientNeed

- **Дата проверки:** 2026-11-03
- **Версия:** см. commit в `IMPLEMENTATION_REPORT.md`
- **Среда:** PostgreSQL 18.6 (compose.test.yaml), Node.js, Vitest 5 / Playwright 1.64

## Предусловия
Клиент риелтора 1.

## Тестовые данные
Синтетическая потребность «аренда коммерческой».

## Действия
1. Создание потребности без следующего действия.
2. Переходы active → paused (без задачи возврата / с ней) → closed (без причины / other без комментария / с причиной) → active → success.
3. Завершение последней задачи active-потребности без следующего шага.
4. Попытка записать closed без причины напрямую в БД.

## Ожидаемый результат
active без next action и paused без Task возврата отклоняются; closed требует stop_reason_code и closed_at; success без причины; история этапов/статусов сохраняется; CHECK в БД блокирует обход.

## Фактический результат
Совпадает с ожидаемым.
