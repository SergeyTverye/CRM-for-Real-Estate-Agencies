## Безопасность, производительность, чистка кода

- Аудит: [v323-security-audit.md](../../security/v323-security-audit.md). Критичных уязвимостей нет. Исправлено: двойная проверка loopback, лимит блоков архива. Остаётся: exceljs → uuid (2 moderate).
- Десктоп: PRAGMA SQLite (запись −45…48 %), батчинг проверок доступа календаря (N+1 устранён), параллельные контрольные даты «Сегодня», FullCalendar вынесен из начального чанка. [Замеры](../../operations/desktop-perf-v323.md).
- Комментарии приведены к простому русскому языку без точки с запятой, следы ИИ-инструментов удалены. Каждая изменённая строка кода проверена скриптом на изменение только комментариев, shell и PowerShell — синтаксическим разбором.

## Ограничения

- Авито и Домклик без ручных действий пользователя объявлений не отдают.
- Циан автоматически работает только при наличии дисплея (десктоп), в серверном Docker — ручная проверка.
- Часть сочетаний локация × тип площадки не поддерживают (явный статус unsupported_filter).
- Установленная копия на ПК пользователя не обновлялась. Установка, удаление и переустановка проверены в CI на Windows Server 2022 и 2025.
