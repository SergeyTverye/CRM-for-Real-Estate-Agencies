# T07. Dry-run и commit импорта обезличенной выборки

- **Дата проверки:** 2026-11-03
- **Версия:** см. commit в `IMPLEMENTATION_REPORT.md`
- **Среда:** PostgreSQL 18.6 (compose.test.yaml), Node.js, Vitest 5 / Playwright 1.64

## Предусловия
Синтетический Excel-файл (scripts/dev/import-sample-builder.ts): один лист, 8 секций, пустой второй лист.

## Тестовые данные
32 строки архива, 22 входящих клиента, 15 объектов, вероятные дубли, неполные и некорректные строки; «паспортные» поля-заглушки.

## Действия
1. Загрузка (только руководитель) и dry-run.
2. Проверка, что рабочие таблицы не изменились, и отчёта по строкам.
3. Commit двух секций, затем остальных.
4. Повторная загрузка того же файла.
5. Отмена задания.

## Ожидаемый результат
Секции найдены по маркеру и заголовкам; секция с чужими заголовками — unrecognized; validation_status ready/warning/invalid/unrecognized и probable_duplicate; паспорт/выдан/регистрация/дата рождения не попадают никуда; commit_result у каждой обработанной строки; rows_read = imported + skipped + error; повторная загрузка не удваивает архив.

## Фактический результат
Совпадает с ожидаемым.
