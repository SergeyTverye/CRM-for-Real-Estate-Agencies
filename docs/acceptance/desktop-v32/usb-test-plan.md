# DT-08: USB/HDD резервная копия и восстановление (синтетический smoke)

## Цель и ограничения

Opt-in runner проверяет зашифрованный архив SQLite + файлов, атомарную запись/проверку на выбранный removable drive, readback и восстановление в отдельное временное поколение. Контрольные данные синтетические: SQLite row и файл 7 MiB. Тест отказа — только искусственный `INJECTED_IO_FAILURE`; физическое отключение USB не имитируется и не заявляется.

Runner создаёт на корне указанного диска новый уникальный `crm-synthetic-*` каталог. Не используется существующий каталог бизнеса. Перед записью проверяется свободная ёмкость. Удаляются только созданные данной попыткой каталоги; перед рекурсивным удалением сверяются абсолютный путь, realpath, отсутствие symlink и принадлежность ожидаемому parent.

## Команда доверенного ручного запуска

Из корня проекта после установки зависимостей, в доверенном локальном контуре:

```powershell
npx tsx scripts/acceptance/usb-backup-live.ts --execute-usb-smoke --drive E:
```

Без обоих opt-in аргументов физический сценарий не стартует. Runner не печатает переменные окружения, содержимое файлов, пароль архива или данные вне синтетического набора. Ожидаемый stdout — одна JSON-строка с фиксированным кодом, числом байт/проверок и названием injected fault.

## Проверки

1. Предусловия: доверенный оператор выбрал правильный removable drive; не менее 128 MiB свободно.
2. Создать синтетическую SQLite запись и 7 MiB файл, сформировать шифрованный архив через production `createArchive` и `SqliteSnapshotValidator`.
3. Передать архив через `RemovableDrive` (`LocalDir` с removable policy), проверить, прочитать обратно и сравнить размер/SHA-256.
4. Восстановить readback через `GenerationStore`/`restoreArchive` в отдельный собственный temp root; проверить контрольную SQLite запись и checksum файла.
5. Проверить контролируемый отказ искусственного target; результат обозначается только как injected IO.

Ожидаемо: `USB_SMOKE_PASS`, 7 MiB контрольный файл, checks=5, `failureMode=INJECTED_IO_NOT_UNPLUG`. Любая ошибка — фиксированный uppercase code без данных ошибки/секретов.

## Результат

План и изолированные unit/fake проверки сами по себе не закрывают DT-08. PASS возможен только после явного запуска доверенным оператором на выбранном USB/HDD и проверки фактического `USB_SMOKE_PASS`; физическое извлечение накопителя этим сценарием не тестируется.
