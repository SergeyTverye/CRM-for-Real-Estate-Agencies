# DT-15

**Статус: PARTIAL**

Условие PASS из ТЗ v3.2.1: Backup перед обновлением, новая версия, миграции и перезапуск сохраняют данные. Ошибка обновления оставляет восстановимый вариант.

Данные: синтетика. Для DT-22/23 — только доверенный локальный verifier с обезличенным выводом.

Фактический результат: В Windows CI официального установщика `71e8765` ([EXE-артефакт](https://github.com/SergeyTverye/CRM-for-Real-Estate-Agencies/actions/runs/42396531730/artifacts/13584259822), SHA-256 `a3e5ab26cbe6bcd249f2f222994052c4f985541c46b81910b9221d3262be311e`, [протокол `71e8765`](installed-71e8765.md)) на Windows Server 2022 и 2025 (`installer-evidence-windows-2022`, `installer-evidence-windows-2025`) прошёл автоматизированный сценарий overinstall с созданием зашифрованного pre-update снимка, сохранением данных и перезапуском. Однако при обновлении на Windows 11 поверх старой сборки `41c39b8` (`b56ec7501a9b9ebc9328f9e1dfc03cf452b8e10611bae0675bb4eb6f4262126b`) в программной папке остались устаревшие `app/package-lock.json` и примеры шаблонов (при чистой установке `71e8765` они не добавляются, но при overinstall не удалялись, из-за чего папка обновления не проходит строгий allowlist). В исходном срезе `bf8538d` подготовлена безопасная очистка доказанных программных ресурсов с отказом при обнаружении пользовательских документов/БД/ключей/junction, которая ещё не проверена в собранном EXE; кроме того, сценарий восстановления после искусственного сбоя обновления на установленном ПК отдельно не подтверждён.

Следующее действие: собрать следующий EXE со срезом `bf8538d`, выполнить overinstall поверх `41c39b8`/`71e8765` на Windows 11 и в CI, подтвердить удаление устаревших программных файлов (`app/package-lock.json`, шаблонов) с прохождением строгого allowlist, сохранность пользовательских данных/pre-update backup и восстановимость при сбое обновления.

Срез подтверждений: текущий исходный срез `bf8538d` (очистка при overinstall подготовлена в исходниках, но ещё не протестирована как собранный EXE); проверенный установщик — `71e8765` ([реестр артефактов](../../desktop/release-artifacts.md)). Исторические срезы `11a2778`, `7e7e47e` и `41c39b8` сохранены.
