Поскольку 104 неоднозначные строки отклонены, 128 скрытых исключены, неподдерживаемые колонки/поля/ссылки остаются в отчёте совместимости, а пересчёт формул в настольном Excel/LibreOffice и экспорт/повторный импорт через UI установленной Windows CRM ещё не проверены, статус карточки остаётся **PARTIAL**.
