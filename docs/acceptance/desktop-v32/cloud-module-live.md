# Облачный LIVE: ограниченный модульный transfer/restore

Срез `11a2778`, 2026-11-06. **PASS модульного сценария; полные DT-09–12/25–27 — PARTIAL.** Ниже переданные координатором результаты, без повторного запуска и чтения секретов.

Фактически выполненная opt-in команда:

```text
node node_modules/tsx/dist/cli.mjs scripts/acceptance/cloud-backup-live.ts --execute-cloud-live --scope=module-transfer-restore
```

Только синтетические БД и файлы; коммерческий Excel не использовался.

Предыдущий `--scope=ui-config-probe` отдельно подтвердил сохранение настроек и read/list 2/2 через настоящую форму руководителя синтетической CRM. Настройки доступны только manager в server и desktop; риелтору фактически отказано API/страницей (403). Это не загрузка/восстановление через установленное приложение.

## Не подтверждено этим прогоном

- Физическое отключение сети: отказы были инъецированы.
- Минимально необходимые IAM-права ключа: анонимный 403 не доказывает least privilege аутентифицированного клиента.
- Полное восстановление установленной Windows CRM, её supervisor и пользовательский путь на другом ПК.
- Полная матрица квот/лимитов/CAS/LOCK и все release gates.

Ранний [smoke](cloud-smoke-live.md) остаётся историческим самостоятельным прогоном. Успех текущего модуля не превращает его ограничения в доказательства готовности установщика.
