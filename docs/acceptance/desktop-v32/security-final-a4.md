# Финальная защита исходников и артефактов a4

Изменение `fingerprint-core.mjs` сохраняет состав проверяемых файлов, архивов и извлекаемых значений, лимиты и SHA-256. Из нормализованных ASCII-фрагментов убрана повторная нормализация. Для любых Unicode-фрагментов сохранён полный исходный путь NFKC/ru-RU/whitespace; это консервативное уточнение по независимому ревью.

Новый синтетический тест сравнивает последовательность, набор форм и обнаружение с прежним алгоритмом для текста, русских строк, комбинируемых символов, совместимых лигатур, HTML/JSON, адресов почты, телефонов и декодированных бинарных данных. Приватные отпечатки в тесты и отчёт не включаются.

Первый локальный прогон: 48 PASS / 1 FAIL; отказ — EPERM Windows sandbox при создании синтетической junction, до исполнения проверки защиты. Повтор вне sandbox: **49/49 PASS**. После консервативного уточнения ASCII/Unicode отдельные 4 теста эквивалентности также PASS; scoped lint и typecheck PASS. Штатный pre-commit выполняет полную проверку окончательного индекса и блокирует коммит при ошибке. Проверки не отключались.
