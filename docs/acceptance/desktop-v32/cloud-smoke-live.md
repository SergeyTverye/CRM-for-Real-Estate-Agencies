# Реальный облачный smoke-тест резервирования (синтетика)

Дата: 2026-11-06 14:40:21 UTC. Режим: LIVE, данные синтетические (тестовая SQLite-база и два файла, в том числе 7 МБ для multipart/частей).
Команда: `npx tsx scripts/desktop/cloud-smoke.ts --execute-real-cloud-smoke` (учётные данные читаются из `D:\crm-secrets\clouds.env` вне репозитория, в вывод не попадают).

Сценарий для каждого направления: создание зашифрованного `.crmbackup` (AES-256-GCM, scrypt) → постановка в очередь репликации на оба облака одним архивом → загрузка → проверка (контрольное скачивание и SHA-256) → скачивание → расшифровка и восстановление в отдельный каталог → сверка файла → удаление только этого синтетического объекта.

Результат:

```json
{"results":[{"destination":"yandex","status":"restored"},{"destination":"mailru","status":"restored"}]}
```

Это подтверждает работоспособность адаптеров Yandex Object Storage (S3, multipart) и Облака Mail.ru (WebDAV, части) и восстановление из каждого облака на уровне модуля. Испытания через интерфейс установленного приложения (DT-09, DT-10), отказ одного облака (DT-11), обрыв сети (DT-12) и проверки прав ключа (DT-25/DT-26) выполняются отдельно.
