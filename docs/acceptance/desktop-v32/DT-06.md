## История попыток (не PASS)

- Ранние попытки: проблема с quoting ACL/фикстуры, загрузчик TSX.
- Причина отказа init после завершения переноса core: host SQL CRLF vs installed LF. Обе миграции нормализованы до одинакового содержимого; source SQL теперь точно соответствует официальным tracked LF bytes. Baseline SHA-256: `e7fb13fe26784353496bcdf72e438201f9463e2110302a4d3825322c172ef3eb` / queue `48bb2eeaa0a909610d9f5026ab47df219a6ad09f35f082b41599df8f2fec9ee6`. История применённых БД не переписывалась, проверки не ослаблялись.
- Детерминированный fix генерации + immutable baseline guard — source tooling под фокусными тестами; старая полная регенерация baseline добавляла бы новые модели, поэтому отброшена/восстановлены tracked файлы до proof. Это не заявляется как изменение installed runtime.
