# DT-06

**Статус: PARTIAL**

Условие PASS из ТЗ v3.2.1: Перенос PG→SQLite на тестовой копии сохраняет ID, связи, документы, версии шаблонов и контрольные суммы; PostgreSQL не изменён.

Данные: синтетика. Для DT-22/23 — только доверенный локальный verifier с обезличенным выводом.

Фактический результат: Скрипт и модульная проверка переноса PG→SQLite с сохранением ID, связей, документов, версий шаблонов и контрольных сумм без модификации исходной PostgreSQL подтверждены на синтетической базе в рамках [SQLite этапа 2](../../desktop/sqlite-stage2.md), а также входят в 398 SQLite PASS Windows CI сборки `71e8765` ([протокол `71e8765`](installed-71e8765.md)) и 402 SQLite PASS локальной [регрессии 2026-11-07](regression-20261107.md). Однако сквозной перенос тестовой копии PostgreSQL непосредственно в установленную Windows CRM с открытием перенесённых записей и документов через десктопный интерфейс ещё не выполнен.

Следующее действие: выполнить миграцию тестовой копии PostgreSQL в установленную Windows CRM, сверить ID, связи, версии шаблонов, SHA-256 документов и неизменность исходной PostgreSQL, затем проверить открытие мигрированных данных в приложении.

Срез подтверждений: текущий срез `bf8538d`; проверенный официальный установщик — `71e8765` ([EXE-артефакт](https://github.com/SergeyTverye/CRM-for-Real-Estate-Agencies/actions/runs/42396531730/artifacts/13584259822), SHA-256 `a3e5ab26cbe6bcd249f2f222994052c4f985541c46b81910b9221d3262be311e`, [реестр артефактов](../../desktop/release-artifacts.md)).
