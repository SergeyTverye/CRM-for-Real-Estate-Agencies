Fault-injection transaction rollback, идемпотентный commit, retry, повторный импорт экспортированного файла (0 новых записей), RBAC, неизменность source SHA и cleanup PASS на обеих БД.

Прежние остановки до commit и ожидание профиля больше не являются текущим результатом.
