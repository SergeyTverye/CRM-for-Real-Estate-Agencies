# Независимое ревью v3.2.1

07.11.2026, публичный код и синтетические тесты. Реальные Excel, учётные данные и рабочие файлы ревьюерам не передавались.

Iceman Contributor Free через OpenCode проверил manager-only API, Origin/CSRF, write-only secrets, защищённый archive/staging, поколения restore и native file import. Три первоначальных замечания перепроверены по полным путям выполнения и сняты: пустой destination отсекается до callback, native import не возвращает выбранный путь, restore возвращает уже активированный каталог. Подтверждённых CRITICAL/HIGH по проверенной области не осталось. Это статическое ревью, а не гарантия отсутствия дефектов.

Beam Free независимо проверил NSIS hooks, supervisor, Rust shell и installer harness. Подтверждённых дефектов установки/удаления статически не выявлено. Остались условия фактической проверки: Windows lifecycle, завершение дочерних процессов, ACL, нативные диалоги и переключение поколения. Сборка сама по себе их не закрывает.

Интеграция дополнительно устранила пропущенную передачу `NATIVE_IMPORT` из Rust supervisor и гонку подписки на завершение быстрого тестового процесса. Рабочие копии native import ограничены по количеству/объёму; обычные резервные копии и входной snapshot защищены от удаления до переключения. Изменение восстановления блокировки после аварии проверяется отдельным набором synthetic child-exit/concurrency tests.

Проверки сессий, RBAC/IDOR, финансов и AI-бюджета входят в [двойную регрессию](regression-final.md). Реальные облачные module restore — отдельное [LIVE-доказательство](cloud-module-live.md); оно не доказывает минимальные IAM-права или весь установленный Windows-сценарий. Фактические Windows результаты необходимо связать с конкретным EXE/SHA перед закрытием DT.
