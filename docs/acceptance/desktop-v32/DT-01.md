**Статус: BLOCKED**

Условие PASS из ТЗ v3.2.1: На чистой Windows 10 x64 22H2 запускается единый EXE без Docker, PostgreSQL, Node.js, Git и интернет-соединения.

Данные: синтетика. Для DT-22/23 — только доверенный локальный verifier с обезличенным выводом.

Фактический результат: Чистые потребительские Windows 10 22H2 и Windows 11 x64 офлайн-VM недоступны по явному решению пользователя. Официальный установщик `71e8765` ([EXE-артефакт GitHub Actions](https://github.com/SergeyTverye/CRM-for-Real-Estate-Agencies/actions/runs/42396531730/artifacts/13584259822), 585 603 587 байт, SHA-256 `a3e5ab26cbe6bcd249f2f222994052c4f985541c46b81910b9221d3262be311e`, launcher `8ac04258cd7c963e1bfcfec918f68e3bfd181c52398f058ef4f68a5f718c2ea8`, Node 24.15.0, SQLite 3.51.2, Chromium 156.0.8078.4) прошёл полный installer lifecycle на GitHub Actions Windows Server 2022/2025 и штатную установку с проверкой браузерных сценариев на текущем Windows 11 ПК ([протокол `71e8765`](installed-71e8765.md), [реестр артефактов](../../desktop/release-artifacts.md)), однако эти окружения не эквивалентны чистой потребительской Windows 10 x64 22H2 без интернета.

Следующее действие: карточка остаётся BLOCKED по решению пользователя об отсутствии чистой потребительской Windows 10 x64 22H2 VM; при изменении решения — выполнить офлайн-установку и запуск финального EXE на чистой Windows 10 x64 22H2 VM без предустановленных Docker, PostgreSQL, Node.js и Git.
