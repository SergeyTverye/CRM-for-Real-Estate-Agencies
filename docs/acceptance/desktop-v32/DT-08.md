# DT-08

**Статус: PARTIAL**

Условие PASS из ТЗ v3.2.1: Экспорт на USB/HDD и восстановление без интернета проходят; случайное отключение носителя не портит исходную базу.

Данные: синтетика. Для DT-22/23 — только доверенный локальный verifier с обезличенным выводом.

Фактический результат 2026-11-06: физический внешний диск подтверждён `Get-Disk` как USB (DiskNumber 2), `Get-Partition` — буква E:. Доверенный `scripts/acceptance/usb-backup-live.ts --execute-usb-smoke --drive E:` создал новый собственный каталог, записал зашифрованный архив, проверил запись, считал его обратно и восстановил SQLite в отдельный временный каталог. Контрольная строка и SHA-256 файла совпали. Результат после cleanup: `USB_SMOKE_PASS`, архив 7354252 байта, контрольный файл 7340032 байта, 5 проверок. Другие каталоги/данные USB не изменялись.

Отказ проверен только как контролируемая ошибка I/O (`INJECTED_IO_NOT_UNPLUG`), физическое отключение работающего диска не выполнялось. Это модульный restore синтетической SQLite, а не доказательство пользовательского пути установленной CRM. Условие целиком остаётся PARTIAL до этого пути и проверки внезапного извлечения.

Следующее действие: зафиксировать команды, окружение, SHA, действия и доказательства требуемого пользовательского сценария. Статус менять только по фактическому результату.

Срез подтверждений: `11a2778`; новый CI ожидается, EXE пока нет. Native file restore реализован, но системный picker установленной CRM не проверен. Модульный USB PASS не закрывает полный DT.
