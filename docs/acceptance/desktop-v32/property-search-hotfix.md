# Property search hotfix — desktop v32 (pending acceptance)

Статус: **NOT RUN / PENDING**. Интегрированная сборка, браузер, EXE и живые площадки не проверялись. Никаких PASS-утверждений нет.

## Причина дефекта

Desktop supervisor наследовал дефолтные env kill-switches `AI_ENABLED=false`, `SCRAPER_ENABLED=false`, `YANDEX_WEB_SEARCH_ENABLED=false`, `YANDEX_WEB_SEARCH_AUTO_FALLBACK=false`, даже если в сохранённых настройках значения были `true`. В `src/modules/property-search/application/dependencies.ts` эффективные флаги вычисляются как `ENV && persistedSetting`, поэтому постоянные пользовательские настройки фактически не применялись. Патч меняет только дефолт незаданных потолков рабочего стола на `true` (`env[flag] ??= 'true'` в `scripts/desktop/runtime/supervisor.mjs::configureSearchRuntime`); явный `false` оператора сохраняется, лимиты бюджета не повышаются. Серверные kill-switch и лимиты остаются приоритетными.

## Отдельное подключение Яндекс AI

- AI-ключ и каталог задаются отдельно от переключателя ИИ: через `/settings/ai` (UI, только запись, DPAPI текущего профиля Windows) или через ENV сервера.
- Ключ/каталог никогда не возвращаются в браузер, не логируются и не сохраняются в открытом виде.
- Ввод через UI доступен только роли руководителя (manager-only) и только при локальном хранилище; в серверном режиме ключи задаются администратором ENV.
- Сервер использует ENV и метаданные только для чтения при отсутствии локального хранилища; отсутствие ключа даёт статус `credentials_missing` и сообщение «Требуется подключение Яндекс AI», а не «ИИ отключён».
- Состояния готовности: `disabled_by_server`, `disabled_by_settings`, `credential_store_unavailable`, `credentials_missing`, `ready`.

## Источники и маршруты

- Отдельная страница `/settings/sources` (только руководитель): глобальное включение скрапера/браузерного режима и площадок `cian`, `mirkvartir`, `onrealt`, `domclick`, `yandex`, `youla`, `avito`.
- `/settings/ai`: настройки и бюджет Яндекс AI, включая подключение ключа/каталога.
- Навигация: «Источники поиска» и «Настройки Яндекс AI».

## Фильтры поиска

- Компактные основные фильтры: город, операция, цена, площадь, назначение, площадки; расширенные — сворачиваемый блок «Расширенные фильтры» с сохранением выбранных условий, счётчиком активных и отдельным сбросом только расширенных.
- Подсказки (tooltips) доступны для фильтров; «Жилая» (`residential`) отображается как «Жилая» и смешивается по ИЛИ с коммерческими назначениями.
- Неизвестное условие (например, этаж) не считается подтверждением и попадает в «требуют проверки», а не отбрасывается.
- Частичный отказ источника (`blocked`/`timeout`/`error`) не снимает объект и не равен пустой выдаче; при partial успешная выдача сохраняется.
